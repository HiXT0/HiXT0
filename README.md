## Featured Projects

### [Mini Redis](https://github.com/HiXT0/java-mini-redis-server)
A Redis-inspired in-memory database server written from scratch in Java 21 using only the standard library. It handles many simultaneous TCP clients, speaks the RESP2 protocol, and supports strings, lists, sets, key expiration and atomic counters. Mutations are written to an append-only file with CRC32 checksums and replayed on startup. Includes a CLI client, a JUnit 5 suite covering concurrency, persistence ordering and networking, and a benchmark utility.
`Java 21` · `Maven` · `JUnit 5` · `TCP / RESP2` · `Concurrency`

### [Prism17: Evidence-Grounded SDG Disclosure Auditor](https://github.com/HiXT0/Prism17)
Reads corporate sustainability and BRSR reports and produces an audit report that maps passages to UN SDG targets, grades how concrete each commitment is with a deterministic rubric, and ties every finding to a verified quote and page number. Runs fully locally on open-weight models with no paid APIs. Built with a teammate for FIRE 2026 (SDAI session). The working prototype is complete; large-scale accuracy evaluation is still pending, and the repository says so openly.
`Python` · `Ollama` · `FAISS` · `Streamlit` · `PyMuPDF`

### [TaskFlow Pro](https://github.com/HiXT0/TaskFlow-Pro)
A full-stack Kanban task manager with JWT authentication, subtasks, per-task comments and a dashboard with completion analytics. Includes search and filtering, a GitHub Actions workflow, and deployment configs for Vercel and Render.
`React` · `Vite` · `TanStack Query` · `Tailwind CSS` · `Node.js` · `Express` · `SQLite`

### [Social Media Dashboard](https://github.com/HiXT0/social-media-dashboard) *(in active development)*
A multi-platform content management dashboard with email and Google sign-in, protected routes, a rich-text post editor, drafts, media upload, a content calendar and analytics views. Supabase provides auth, Postgres, storage and row-level security. Real publishing integrations are still on the roadmap.
`React` · `TypeScript` · `Vite` · `Supabase` · `TipTap` · `Recharts`

### [Kingdom of Embers](https://github.com/HiXT0/KINGDOM-OF-EMBERS)
A single-player fantasy RPG built in two days as an object-oriented Java exercise, with a console version and a Swing GUI that share the same game logic. Features turn-based combat, a skill system, a village shop, a quest and save/load.
`Java` · `Swing` · `OOP`
